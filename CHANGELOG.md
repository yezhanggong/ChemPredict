# Changelog

All notable project changes are documented here. The project follows semantic versioning for public artifacts, while model promotion remains governed by scientific validation rather than version number alone.

## [4.4.0] - 2026-07-19

### Added

- Bilingual Chinese/English multi-reaction-system interface.
- Registry for one quantitative and eight evidence/refusal reaction systems.
- qmdesc, DBSTEP, differentiating RDKit descriptors, and XGBoost challenger pipelines.
- Group-aware intervals, D-grade high-risk rules, and stronger refusal logic.
- Public data card, contribution guide, roadmap, CI, issue templates, and GitHub Pages deployment.

### Retained

- v4.3 production models for yield and ee because v4.4 challengers failed the predeclared promotion criteria.

### Not included

- No Android APK and no publisher PDF files are distributed in this release.
