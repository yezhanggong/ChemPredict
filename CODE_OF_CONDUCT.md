# Community Code of Conduct

ChemPredict discussions should be technically specific, evidence-based, and respectful. Participants must not harass others, disclose private information, misrepresent model output as experimental fact, or submit data they lack permission to share.

Maintainers may edit, hide, or remove content that violates these expectations, compromises confidentiality, or creates a chemistry safety risk. Scientific disagreement is welcome when claims, assumptions, and supporting evidence are stated clearly.

Report conduct concerns privately to the repository maintainers through GitHub. Do not use a public Issue when the report contains personal or confidential information.
