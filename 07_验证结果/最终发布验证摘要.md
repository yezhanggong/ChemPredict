# ChemPredict v4.4.0 公开发布验证摘要

公开化日期：2026-07-19。

## 1. 公开范围

- 包含：整理数据、模型/门控源码、序列化模型、双语网站、v4.4 留出验证和机器可读审计。
- 排除：论文 PDF、内部审查提示词、虚拟环境、构建缓存、APK、签名文件和本机绝对路径。
- 文献通过 DOI 和用途注册表引用，不改变出版商或作者的原始权利。

## 2. 数据验证

- 条件记录 33 条，底物范围 30 条；训练域 26 条，挑战范围 4 条。
- 目标标签转录固定为 2a-2z 与 3a-3d 的论文值，未为改善指标修改。
- qmdesc、DBSTEP、RDKit/PubChem 和反应体系注册表的语义与完整性检查均保留在 `07_验证结果/data/v4.4.0`。
- 公开 CI 调用 `validate_public_release.py`，并拒绝 PDF、APK、访问令牌和本机路径进入仓库。

## 3. 生产模型

| 目标 | 嵌套整组留出 MAE | RMSE | 最大绝对误差 | R2 | Spearman |
| --- | ---: | ---: | ---: | ---: | ---: |
| 产率 | 8.029 | 10.948 | 30.275 | -0.343 | 0.015 |
| ee | 6.180 | 10.993 | 45.207 | 0.065 | 0.620 |

- v4.4 全候选和手工可部署挑战者均未通过预声明晋级规则，产率和 ee 继续使用 v4.3 冠军。
- 产率模型的负 R2 和近零排序相关性是明确限制，不得描述为高精度预测。
- ee 的最大留出误差为 45.207 点；强对位吸电子底物和环状苄基单例采用 D 级警告或拒绝。

## 4. 软件验证

- Python 适用域与 Python/JavaScript 推理一致性测试共 11 项。
- Playwright 覆盖中文、英文、桌面、移动端、9 个反应体系和 D 级规则。
- GitHub Actions 在每次提交和 Pull Request 上执行公开仓库审计、数据审计、单元测试和浏览器测试。
- GitHub Pages 仅部署 `05_网站` 静态文件，不使用远程推理服务。

## 5. 未完成验证

当前没有独立实验室的永久前瞻测试集，也没有足够数据建立通用的溶剂-催化剂响应面。相关文献压力测试只验证拒绝逻辑，不能替代目标反应的真实外部预测验证。本版本不提供 Android APK。
