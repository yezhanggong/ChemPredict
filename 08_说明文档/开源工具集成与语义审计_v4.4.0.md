# 开源工具集成与语义审计 v4.4.0

## 一、qmdesc 1.0.6

### 实际能力

`qmdesc.predict_descriptors` 返回原子级 Hirshfeld 部分电荷、亲核/亲电 Fukui 指数、NMR 屏蔽，以及键级和键长。模型目标来自 B3LYP/def2-SVP 数据；本项目没有现场运行量子化学计算。

### 与优化提示词的差异

优化提示词要求 HOMO/LUMO 贡献与 Mulliken 电荷，但 qmdesc 1.0.6 API 不提供这些字段。v4.4 没有伪造列名，而是采用实际字段，并在 CSV 中标记 `ml_predicted_b3lyp_def2svp_targets_not_direct_quantum_chemistry`。

### 兼容性与信任边界

qmdesc 1.0.6 的模型检查点使用旧式 PyTorch pickle。PyTorch 2.13 默认安全加载策略与其不兼容；脚本只在加载官方 qmdesc 包内检查点时临时允许旧式加载，随后立即恢复 `torch.load`。因此只能使用锁定来源的官方包，不得把任意外部检查点放入该路径。

- 项目：<https://github.com/yanfeiguan/qmdesc>
- 文档：<https://qmdesc.readthedocs.io/>
- 论文 DOI：<https://doi.org/10.1039/D0SC04823J>
- 本轮 PyPI wheel SHA-256：`f4603b3be54ff82af824847a3b558bb9c252495fd2d41a53acdf78939e9e5fd9`

## 二、DBSTEP 1.1.0

### 构象协议

1. 从人工核对 SMILES 生成 ETKDGv3 构象，固定随机种子。
2. 每个分子尝试 12 个构象，使用 MMFF94；不适用时回退 UFF。
3. 保留最低能量的 5 个构象。
4. 以产物中带腈的 sp3 碳指向芳基骨架的方向定义轴。
5. 输出 B1、B5、L、埋藏体积和分子体积的中位数、最小值、最大值与范围。

### 限制

该轴是产品骨架代理，不是 Cu/L1 结合过渡态。L1 结构未机器可读核实，因此配体 B1/B5/L 保持空值。

- 项目：<https://github.com/patonlab/DBSTEP>
- 论文 DOI：<https://doi.org/10.1021/acs.jcim.0c01367>

## 三、XGBoost 3.3.0

候选限制为深度 1–2、100 棵树、学习率 0.05 或 0.1，并使用 `min_child_weight=2`、`reg_alpha=0.3`、`reg_lambda=10`、行列采样 0.85。随机种子为 4400，单线程训练。

模型导出为 JSON 树，不依赖浏览器端 XGBoost 运行时。Python 与 JavaScript 对 2m ee 挑战者的结果在 10 位小数内一致。

- 文档：<https://xgboost.readthedocs.io/en/stable/python/python_api.html>
- 算法论文 DOI：<https://doi.org/10.1145/2939672.2939785>

## 四、RDKit 2025.09.6

用于 SMILES 解析、结构中心定位、ETKDGv3 构象、MMFF/UFF、分子式核验和 2D 分化描述符。它不把经验 Gasteiger 电荷转换为 DFT/NBO 电荷。

- 官方文档：<https://www.rdkit.org/docs/>

## 五、集成结论

三类工具均已完成离线集成、版本锁定和语义审计，但 qmdesc/DBSTEP 未通过生产晋级。其价值当前主要是：消除描述符完全相同、建立可复现实验管线、记录真实研究缺口，而不是已证明提高泛化精度。
